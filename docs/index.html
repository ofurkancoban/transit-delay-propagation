Feed limitations found so far

  • vehicle_id is never populated on the primary feed (0 of 16.8M rows, confirmed against the raw protobuf). The vehicle-chain / block propagation channel cannot be estimated from this source.
  • direction_id is always the GTFS-RT "unset" sentinel (-1) in realtime, and the static trips.txt omits direction_id/block_id entirely. "Same route and direction" network features reduce to "same route" only, joined via trip_id.
  • Both findings are documented in README.md and will constrain the edge-type ablation in the eventual spatio-temporal GNN.
